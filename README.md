# Open Eye Growth

Phase 1 marketing site for Open Eye Growth. This repo is a single homepage: services, how it works, and pricing. There is no backend, auth, or extra pages.

## Run locally

```bash
npm install
npm run dev
```

The dev server binds to `0.0.0.0` on port **47319**.

Open [http://127.0.0.1:47319](http://127.0.0.1:47319).

## Production build

```bash
npm run build
```

Preview the production build with `npm run preview`.
